Обособленные подразделения

Если заказчик принимает и оплачивает товар через разные ОП (свой КПП, адрес, лицевой счёт), заведите их здесь. В документе появится выбор подразделения, и в счёте, ТОРГ‑12 и УПД будут реквизиты выбранного ОП.

Водителю — точки доставки

Только для водителя, в документы не попадает. Укажите телефон кладовщика или того, кто встречает машину, часы приёмки и как подъехать — это подставится в маршрут во вкладке «Водителю».

Контракты и договоры

Каждый контракт привязан к конкретному исполнителю. В документе при выборе контракта поставщик, основание и ИКЗ подставятся сами, а по цене контракта считается остаток.

Нумерация документов

У каждого заказчика своя нумерация. Новый документ получает номер «последний в журнале + 1». Если раньше документы для этого заказчика делали в 1С или Т‑Банке — один раз впишите, с какого номера продолжить.

Цены для заказчика

Пустая цена — товара нет в прайсе заказчика, в документ подставится базовая цена. Товары общие для всех заказчиков, цены у каждого свои.

Сопоставить с Порталом поставщиков

Нужно один раз на контракт, чтобы выгружать УПД в XML. На Портале поставщиков откройте контракт → блок «Сведения о спецификациях» → «Выгрузить в xls», и загрузите этот файл сюда — позиции сопоставятся с вашими товарами по цене. ID СТЕ подтягиваются из УПД, уже отправленных через Портал: загрузите сюда XML такого документа.

Загрузить прайс из таблицы

Выделите в Google Таблице или Excel строки с товарами вместе с заголовком (нужны колонки «Товар» или «Наименование», «Ед.» и «Цена»), скопируйте и вставьте сюда. Новые товары добавятся в номенклатуру, цены запишутся этому заказчику. Существующие товары узнаются по названию.
