# Магазин «Фруктовый Дом» (тестовая версия)

Отдельная страница магазина, к генератору документов не относится.
Адрес: https://dskoby-maker.github.io/frudom-docs/shop/

- `index.html` — страница магазина (каталог, корзина, кабинет компании).
- `catalog.json` — товары и цены, выгрузка из листа «Витрина» таблицы «Документы ФД».

Пока это витрина: заказы и оплата не принимаются. Позже магазин переедет в свой репозиторий и на сервер в России (оплата Т-Банк).
