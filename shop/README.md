# Магазин «Фруктовый Дом» (frudom.ru)

Отдельная страница магазина, к генератору документов не относится.
Тестовый адрес: https://dskoby-maker.github.io/frudom-docs/shop/

- `index.html` — страница магазина (каталог, корзина, заказ без НДС, заказ со счётом с НДС).
- `embed.js` — загрузчик для Тильды. В блок HTML на странице frudom.ru вставляется одна строка:
  `<div id="fs-shop"></div><script src="https://dskoby-maker.github.io/frudom-docs/shop/embed.js"></script>`
- `catalog.json` — запасной каталог, если таблица недоступна.

Каталог берётся из листа «Витрина» таблицы «Документы ФД» (действие `shopCatalog` в Code.gs),
заказы записываются на лист «Заказы с сайта» и приходят письмом владельцу (действие `shopOrder`).
Оба действия открыты без пароля и ничего, кроме витрины и приёма заказа, не отдают.
